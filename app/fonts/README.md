# Goalio fonts

Chinese UI text uses ZCOOL KuaiLe to echo the rounded, hand-drawn lettering in the user's reference. Latin text and numbers use Nunito, keeping financial values easy to distinguish.

Font sources:

- [ZCOOL KuaiLe](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile)
- [Nunito](https://github.com/google/fonts/tree/main/ofl/nunito)

Both are distributed under the SIL Open Font License. The original licenses are included alongside the unmodified font files. Next.js serves the fonts locally; visitors do not request fonts from Google or a third-party CDN.
