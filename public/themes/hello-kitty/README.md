# Hello Kitty 示例背景

五张由内置 Image Gen 生成的独立无字背景，配合已确认的 Goalio 首页效果图使用：

- `goal.png`：目标概览，樱花野餐。
- `progress.png`：目标进度，浅粉格纹与蝴蝶结。
- `completion.png`：预计准备好，樱花与台历。
- `daily.png`：明天的基本开销，草莓早餐。
- `spending.png`：当前最多可额外支出，蝴蝶结钱包。

图片为内置示例资源。用户自行选择的图片由浏览器压缩后保存在本地 localStorage，不写入此目录，不上传服务器。所有金额、日期与其他页面文字由原有组件实时显示。
