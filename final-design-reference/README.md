# Goalio 最终设计参考

本文件夹中的 12 张图片是 Goalio 后续网站设计与开发的正式视觉基准。

## 固定视觉方向

- 风格：克制、简洁、轻盈，遵循苹果式信息呈现与交互节奏
- 主色：黑色、白色、Apple Blue
- 页面：一次只突出一个主要任务，保持充足留白
- 字体：优先使用 SF Pro / PingFang SC 系统字体
- 控件：大圆角、细边框、轻灰背景、清晰层级
- 动效：轻柔、连续、短促，服务于页面状态变化
- 避免：彩色渐变、玻璃拟态、装饰性图标、过度卡片化、强烈阴影

## 页面顺序

1. `01-welcome.png`：欢迎与开始设置
2. `02-future-income.png`：收入周期与到账信息
3. `03-daily-food.png`：每日饮食预算
4. `04-fixed-expenses.png`：固定支出
5. `05-savings-goal.png`：储蓄目标
6. `06-current-balance.png`：首次真实余额
7. `07-daily-balance-input.png`：每日余额输入
8. `08-daily-home-result.png`：每日首页结果
9. `09-purchase-input.png`：消费评估输入
10. `10-purchase-result.png`：消费评估结果
11. `11-settings.png`：设置页
12. `12-goal-complete.png`：目标完成

## 实施约束

开发时应优先匹配这些参考图中的页面结构、留白比例、字号层级、圆角、边框和按钮样式。第 02 张已经采用最终确认的纤细蓝色竖线选择状态。
