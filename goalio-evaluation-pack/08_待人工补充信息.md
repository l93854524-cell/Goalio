# 待人工补充信息

以下信息无法从当前项目中可靠确认，但后续商业化评测可能需要。

## 商业化与渠道

- 小红书商品页或购买入口的真实链接；
- 小红书笔记是否已经发布，以及实际发布时间；
- 当前 ¥3.14 是否仍为正式有效售价，是否有优惠或其他价格；
- 小红书自动发货是否已实际启用；
- 是否已产生真实付款、订单、退款和收入；
- 当前真实销售量、付费用户数和转化率；
- 小红书曝光、点击、收藏、评论、私信和购买漏斗；
- 项目之外仍在使用的宣传素材、海报、销售页和社媒账号。

## 用户与反馈

- 当前注册用户数、活跃用户数和留存；
- 用户来源与实际用户画像；
- 真实用户访谈、问卷、私聊、评论和客服记录；
- 用户报告过的同步、计算、登录或支付问题；
- 用户是否理解“已为目标留好”属于计算结果；
- 用户是否在多设备上使用，以及是否发生过覆盖冲突。

## 线上基础设施

- 线上 Supabase 项目是否已执行当前 migration；
- 生产 RLS 策略是否与仓库文件一致；
- Email/Password provider、Confirm Email、速率限制和 SMTP 的当前配置；
- Supabase 免费项目当前是否在线、是否曾暂停；
- 数据库备份、保留周期、静态加密和恢复方案；
- GitHub Actions 近期部署记录及两套 workflow 是否发生冲突；
- 当前线上版本对应的 commit 与部署时间；
- 线上性能、浏览器兼容性和网络失败率。

## 账号与运营规则

- 忘记密码时维护者的实际支持流程与联系入口；
- 用户删除账号和数据的实际处理流程；
- 隐私政策、用户协议、退款规则是否存在于项目之外；
- 统一邀请码的发放、更新、泄露处理和失效规则；
- 是否计划继续销售当前版本，以及营销素材中哪一版为最终发布版。

## 产品外部事实

- 是否有未纳入仓库的设计稿、研究报告、定价记录或竞品资料；
- 是否有项目外部的销售表、支付截图、财务记录；
- 是否有项目外部的用户反馈数据库；
- 是否存在其他线上域名、镜像部署、原生 App 或小程序。

本清单没有要求补充仓库已经能够确认的 URL、当前材料标价、技术栈、计算公式、账号机制和部署配置。
