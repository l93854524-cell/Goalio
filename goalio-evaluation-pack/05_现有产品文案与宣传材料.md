## 8. 首页结果

- 标题：`正在为「{目标名称}」准备`
- 主指标：`已为目标留好 {金额}`
- 进度：`目标 {目标金额} · 已完成 {百分比}%`
- 正向变化：`今天多留了 {金额}`
- 正向解释：`当前余额照顾好未来生活和固定支出后，又有更多可以安心留给目标。`
- 回撤：`今天的目标进度减少了 {金额}`
- 回撤解释：`最近的余额发生了变化，我先把接下来的生活和固定支出照顾好。`
- 无变化：`今天的目标进度保持不变`
- 无变化解释：`目前的余额刚好适合维持现在的安排。`
- 指标：`预计准备好`、`明天的基本开销`、`明天额外最多可花`
- 可花说明：`这个金额不包含明天的基本开销，不会动用已为目标留好的钱，并已确保按当前计划仍能在目标日期前准备好。实际余额或计划变化后会重新计算。`
- 近期缺口：`近期基本开销还差 {金额}`
- 缺口说明：`按现在的余额，下一笔收入到账前的生活和固定支出还需要补足。`
- 无法按期：`当前的安排还需要一点调整` / `按现在的余额和开销，目标时间可能会晚一些。`
- 信息不足：`还缺少{信息}，暂时无法可靠判断完成日期。`
- 消费入口：`帮我看看能不能买`
- 来源：`GoalioApp.tsx:412-461`

- 加载：`正在把这笔消费放进未来的安排里…`
- 来源：`GoalioApp.tsx:465-482`

### 结果页

| 结果 | 当前文案 |
| --- | --- |
| 资金缺口 | `这笔消费会影响安排` / `未来可能缺少 {金额}` / `建议降低预算，或等余额更充足时再购买。` |
| 信息不足 | `现在还无法放心判断` / `还缺少一些信息` |
| 无完成日期 | `这笔消费会影响目标` / `完成时间将无法确定` |
| 进度减少、日期不变 | `仍然可以购买` / `预计完成时间保持不变` / `会挤占当前已留金额 {金额}，后续结余将优先补回。` |
| 无影响 | `可以安心购买` / `这笔消费不会影响目标进度` / `预计完成时间保持不变` |
| 截止日前推迟 | `仍然可以购买` / `预计会推迟 {天数} 天` |
| 晚于计划 | `这笔消费会让目标晚于计划` / `晚于计划 {天数} 天` |

替代方案：

- `降低预算`
- `今天最多花 {金额}`
- `保持原来的完成时间`
- `延后购买`
- `{日期}后购买`

操作：`返回首页`、`修改商品或金额`。来源：`GoalioApp.tsx:486-538`。
